Team Task Manager

Description:
A full-stack web application where admins can create projects, assign tasks to members, and track task progress.

Features:
- User Signup/Login
- Role-based access (Admin/Member)
- Project Management
- Task Assignment
- Task Status Tracking
- Dashboard
- MySQL Database Integration
- Live Deployment

Tech Stack:
Frontend: React.js
Backend: Node.js, Express.js
Database: MySQL
Deployment: Vercel + Railway

Admin Features:
- Create/Delete Projects
- Create/Delete Tasks
- Assign Tasks to Members

Member Features:
- View Assigned Tasks
- Update Task Status

Deployment Links:
Frontend: Vercel
Backend & Database: Railway
