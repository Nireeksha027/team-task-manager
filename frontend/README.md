Team Task Manager

Description:
A full-stack web application where admins can create projects, assign tasks to members, and track task progress using role-based access control.

Features:

* User Signup/Login
* Role-based access (Admin/Member)
* Project Management
* Task Assignment
* Task Status Tracking
* Dashboard with overdue tasks
* MySQL Database Integration
* Live Deployment

Tech Stack:
Frontend: React.js
Backend: Node.js, Express.js
Database: MySQL
Deployment: Vercel + Railway

Admin Features:

* Create/Delete Projects
* Create/Delete Tasks
* Assign Tasks to Members

Member Features:

* View Assigned Tasks
* Update Task Status

Live Application URL:
https://team-task-manager-eight-alpha.vercel.app

GitHub Repository:
https://github.com/Nireeksha027/team-task-manager

Deployment Details:

* Frontend deployed on Vercel
* Backend API and MySQL database deployed on Railway
